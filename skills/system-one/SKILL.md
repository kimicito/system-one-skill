# System One — decision pattern (выбор вместо генерации)

Паттерн «System One» из экосистемы Jev (TypeSafe AI): когда задача сводится к **выбору из ограниченного множества кандидатов**, не генерируй ответ — скорь кандидатов и выбирай. Ответ всегда валиден по построению, дешевле и быстрее.

## Когда применять

✅ Подходит (decision-задачи):
- классификация / роутинг (письмо → лейбл, задача → статус)
- выбор из вариантов (оффер поставщика, лучший хук, инструмент)
- оценка по правилам (голоса, требования конференции, чек-листы)
- триаж с порогом уверенности (уверен → решил; нет → escalate в полный разбор)

❌ Не подходит (generation-задачи):
- многошаговый расчёт, математика (нужен chain-of-thought)
- открытая генерация текста (статьи, письма с новым содержанием)
- задачи, где множество кандидатов не ограничено заранее

## Рабочий процесс (чек-лист)

1. **Контракт**: сформулировать вопрос и явный список кандидатов (≤20, идеально ≤8)
2. **Скоринг**: выбрать режим
   - `embed` — смысловая близость через локальный embed-сервер (hy-memory, порт 7997)
   - `matrix` — взвешенная матрица критериев (без внешних зависимостей)
3. **Порог**: если топ-скор < 0.55 (embed) или разрыв топ-2 < 0.05 — не выбирать, escalate
4. **Проверка**: правый хвост — правило-валидация выбранного варианта (запрещённые слова, обязательные поля)
5. **Объяснение**: отчёт «выбрал X, скоры такие-то, уверенность такая-то» — всегда с цифрами

## CLI

```bash
PY=/root/.openclaw/workspace/.venvs/hy-memory/bin/python
D=/root/.openclaw/workspace/skills/system-one/scripts/decide.py

# embed-режим (нужен embed-сервер на 7997):
$PY $D embed --query "последний дедлайн статьи" \
  --options "18.10 конференция,послезавтра созвон,просрочено" -n 3

# matrix-режим (веса критериев):
$PY $D matrix --spec examples/supplier_matrix.json
```

Вывод: JSON с выбором, скорами всех кандидатов и уверенностью.

## Интеграция в мои процессы

- **tasks_шефа**: роутинг задач на статусы (делаю/wait/gate⚠️/просрочено) — embed-режим по тексту задачи + правила дедлайнов
- **почта**: триаж писем (срочное/задача/спам/личное) → ниже порога = читаю полностью
- **PriceWize**: выбор оффера по matrix (цена, доставка, наличие, риск)
- **content-voices**: выбор хука из кандидатов → правый хвост на запрещённое «—» и ключи голоса

## Эталонный паттерн для агентов (из browser-use/jev-ultrafast)

Наблюдение → индексированное пространство легальных действий → выбор → выполнение кода → перепроверка состояния. Генеративная модель подключается только когда выбранное действие требует нового текста.

## Ограничения

- embed-режим требует живого embed-сервера (systemctl status hymemory-embed); fallback — matrix-режим
- скилл не заменяет рассуждение: при сомнении (п.3 чек-листа) всегда escalate
- идея из Jev: до 255 вариантов на выбор; больше — двухстадийно (score → choice), у нас это `embed -n` → ручной топ
