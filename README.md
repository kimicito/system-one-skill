# system-one-skill

Паттерн «System One» (по мотивам Jev от TypeSafe AI) для OpenClaw: **когда задача — выбор из ограниченного множества кандидатов, не генерируй ответ, а скорь кандидатов и выбирай**. Ответ валиден по построению, дёшево, быстро.

## Что внутри

- `skills/system-one/SKILL.md` — чек-лист применимости (когда выбирать, когда рассуждать), рабочий процесс с порогами escalate
- `skills/system-one/scripts/decide.py` — CLI двух режимов:
  - **embed** — смысловой скоринг через любой OpenAI-совместимый embed-сервер (по умолчанию `127.0.0.1:7997`, см. hy-memory-local)
  - **matrix** — взвешенная матрица критериев из JSON (без внешних зависимостей)
- `skills/system-one/examples/supplier_matrix.json` — пример выбора поставщика

## Пороги (по умолчанию)

- `confidence < 0.55` → escalate (не выбирать, отдать на полный разбор)
- разрыв топ-1 и топ-2 `< 0.05` → escalate

## Пример

```bash
python decide.py embed --query "срочное письмо от клиента" \
  --options "срочное;задача;спам;личное"
python decide.py matrix --spec examples/supplier_matrix.json
```

Вывод — JSON: выбор, уверенность, отрыв, скоры всех кандидатов.

## Границы применимости

✅ классификация, роутинг, выбор из вариантов, оценка по правилам, триаж
❌ многошаговый расчёт, математика, открытая генерация текста
При сомнении — escalate. Идея из Jev: до 255 кандидатов на выбор; больше — двухстадийно.
